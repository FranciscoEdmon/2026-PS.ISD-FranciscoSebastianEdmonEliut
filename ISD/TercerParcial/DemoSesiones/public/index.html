JWT · Token de acceso

Inicia sesión con JWT, observa el token y úsalo como Authorization: Bearer. A diferencia de la cookie, el servidor no guarda una sesión para cada token; al renovar o cerrar sesión, el token anterior queda en la lista negra hasta que expire.
